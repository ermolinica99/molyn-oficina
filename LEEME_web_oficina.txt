============================================================
  MOLYN · Web de Oficina — COMPLETA
============================================================

Version WEB de toda la app de escritorio. Se abre en el
navegador, SIN instalar nada y SIN que el antivirus la
bloquee. Conectada a tu Supabase real.

LAS 10 PAGINAS:
  OPERACION
   - Dashboard: KPIs, filtros, forzar diario
   - Produccion: subir parte, lanzar OT, parte imprimible + QR
   - Ordenes de trabajo: fabricar, cerrar, anular, reimprimir QR
   - Inventario fisico: altas y bajas de stock
   - Usuarios: alta de plantilla con rol y PIN
  ANALISIS
   - Productividad: rendimiento por operario (con fecha)
   - Tiempo por nucleo: tiempos medios aprendidos
   - Aprobaciones: validar inventarios de planta
  AJUSTES
   - Alta masiva: importar catalogo desde Excel
   - Configuracion: parametros + lotes por programa

ACTUALIZAR EN GITHUB
------------------------------------------------------------
Sube este index.html al repo molyn-oficina (reemplaza el
anterior). En 1-2 min GitHub Pages se actualiza solo.
URL: https://ermolinica99.github.io/molyn-oficina/

PRUDENCIA AL ESTRENAR
 - Las paginas que escriben datos (Produccion, Ordenes,
   Inventario, Usuarios, Aprobaciones, Configuracion, Alta
   masiva) estan probadas cargando datos, pero la PRIMERA
   vez que uses cada accion que crea/borra/modifica, hazlo
   con un caso de prueba y verifica el resultado.
 - Para imprimir (parte + etiquetas), permite las ventanas
   emergentes del navegador para esta pagina.

------------------------------------------------------------
PUESTA EN MARCHA (checklist antes del primer día)
------------------------------------------------------------
 1. Supabase -> SQL Editor: ejecutar permitir_borrar_unidades.sql
    (sin él, Cerrar/Anular OT y las bajas de inventario no pueden
    borrar unidades; la web ahora lo detecta y avisa).
 2. GitHub -> molyn-oficina -> Settings -> Secrets -> Actions:
    comprobar que existe SUPABASE_DB_URL (lo usan el backup diario
    y el cierre automático de turnos). En la pestaña Actions, lanzar
    a mano "Backup base de datos MOLYN" y ver que sale en verde.
 3. En cada tablet de planta: abrir https://ermolinica99.github.io/molyn-planta/,
    "Añadir a pantalla de inicio", entrar con el PIN del puesto
    (la sesión del puesto se queda guardada) y permitir la cámara.
 4. En el ordenador de oficina: permitir ventanas emergentes para
    esta web (partes y etiquetas QR). Si se bloquean, abajo a la
    derecha aparece un botón para abrirlas.
 5. Prueba en vacío: lanzar un parte pequeño, fabricarlo en planta,
    consumirlo con el encargado, pedir una baja desde planta y
    aprobarla en Oficina. Comprobar el stock en el Dashboard.
